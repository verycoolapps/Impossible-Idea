# Genius Candidate Framework

Pick ONE crossing result, test it with 4 hard questions.

## 1. Hidden Logic
Why does it secretly make sense? 1-2 sentences of real economic/psychological cause and effect. Not optimism.

## 2. Steelman
The strongest argument it COULD succeed, based on real behavior.

## 3. Pre-mortem
Imagine it fails a year from now. Write the most plausible cause. HONEST. If you can't → too generic.

## 4. Smallest Test
An experiment ≤7 days, ≤ minimal cost, that proves/disproves the idea.

## Output
See templates/genius-candidate-card.md.

## Guardrail
If your Hidden Logic reads like marketing copy, it's optimism — rewrite until it names a real mechanism someone would pay for.
